# TECHNIGRAF Betriebssystem

Interne Anwendung der TECHNIGRAF GmbH für Ersatzteilauskunft, Lager, Inventur,
Fertigung, Einkauf und Belege.

**Download: https://chrismhn.github.io/technigraf-app/**

Dieses Repository enthält nur die Installationsdateien und die Downloadseite.
Der Quellcode wird separat gepflegt.

| System | Datei |
|---|---|
| Windows 10/11 | `TECHNIGRAF-Betriebssystem-Setup-0.1.0.exe` |
| macOS (Intel) | `TECHNIGRAF-Betriebssystem-0.1.0.dmg` |
| macOS (Apple Silicon) | `TECHNIGRAF-Betriebssystem-0.1.0-arm64.dmg` |

Die Anwendung aktualisiert sich selbst aus den Releases dieses Repositories.
